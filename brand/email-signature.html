Gmail (on a computer):

  1. Tap Copy signature above.
  2. In Gmail, open Settings (gear) → See all settings → General → Signature.
  3. Create a new signature, paste into the box, then Save changes at the bottom.

Outlook: Settings → Mail → Compose and reply → Email signature, paste, save.

Apple Mail on iPhone: Settings → Apps → Mail → Signature, paste. The iPhone may drop the logo; that's normal.

If the paste loses formatting, use Copy HTML instead in apps that accept HTML signatures.
